# 🧠 도파민 클리너 (Dopamine Cleaner)

현대인의 뇌를 잠식하는 잡생각, 숏폼 알고리즘, 졸음 몬스터를 시원하게 정화하는 **2D 탑다운 뱀서라이크(Survivors-like) 로그라이트 액션 게임**입니다.

---

## 🎮 게임 정보

* **엔진**: Unity 6 (6000.6.4f1)
* **장르**: 2D Roguelite, Survivors-like, Bullet Hell
* **개발 언어**: C# (.NET Standard)
* **타겟 플랫폼**: PC Windows 11 / 10 (64-bit), 모바일
* **외부 종속성**: 외부 상용 에셋 0% (완전한 절차적 프로시저럴 C# 텍스처 & 오디오 신디사이저 렌더링)
* **무설치 포터블 패키지**: 빌드된 ZIP 파일 압축 해제 후 즉시 실행 가능

---

## 🚀 친구에게 공유하고 Windows 11에서 실행하는 방법

### 1. 배포 패키지 위치
프로젝트 루트의 `Builds/` 디렉터리에 배포용 실행 파일 및 압축 파일이 준비되어 있습니다:
* **무설치 압축 패키지**: `Builds/DopamineCleaner_Windows11_v1.0.zip` (약 42.8 MB)
* **실행 파일**: `Builds/DopamineCleaner_Win64/DopamineCleaner.exe`

### 2. 친구에게 시켜보는 방법 (3단계)
1. **ZIP 파일 전달**: 카카오톡, 디스코드, 구글 드라이브, 대용량 메일 등으로 `DopamineCleaner_Windows11_v1.0.zip` 파일을 친구에게 전송합니다.
2. **압축 풀기**: 친구 컴퓨터(Windows 10 / 11)에서 원하는 폴더에 압축을 풉니다.
3. **더블 클릭 실행**: 폴더 안의 **`DopamineCleaner.exe`**를 더블 클릭하면 설치 없이 즉시 부드러운 60 FPS로 게임이 실행됩니다!
> *(Windows SmartScreen 파란색 경고창이 뜰 경우: `추가 정보` 클릭 $\rightarrow$ `실행` 버튼을 누르면 정상 실행됩니다.)*

## 🕹️ 조작법 (Controls)

| 키 | 동작 | 상세 설명 |
| :--- | :--- | :--- |
| **W, A, S, D** / 방향키 | 2D 8방향 이동 | 플레이어 기동 |
| **Space** / **Left Shift** | 무적 회피 대시 (Dash) | 0.25초 완전 무적 및 2.4배 속도 도약 |
| **Q** | ⚡ 요원 고유 궁극기 | 요원별 필살기 전개 (빗자루 대청소 / 법적 면책권 / 긴급 통제 / 자본의 힘) |
| **E** | 🎰 럭키 자판기 상호작용 | 필드 슬롯머신 배팅 및 하이리스크 암거래 계약 |
| **1** (숫자키 1) | 💊 응급 구급약 사용 | 인벤토리 비상약 즉시 투약 (HP +40) |
| **P** / **ESC** | 일시정지 (Pause) / 설정 | 장비 현황판, BGM/SFX 볼륨 조절, 조기 철수 정산 |
| **마우스 클릭** | UI 상호작용 | 레벨업 카드 선택 및 본부 시설 이용 |

## ⚔️ 핵심 시스템 및 신규 추가 기능

### 1. ⚡ 엘리트 몬스터 변이 수식어 (Elite Affixes)
* **네온 오라 엘리트 몬스터**: 25초 이후 일정 확률로 거대화된 엘리트 몹 출현.
  * 🧲 **[보석 강탈자 (도파민 도둑)]**: 바닥의 경험치 보석을 빨아들여 흡수하면서 체력과 크기 성장 (처치 시 훔친 보석 2배 환급!).
  * 💬 **[알림 폭풍]**: 피격 시 35% 확률로 6방향 스팸 반사 탄환 방출.
  * 🛡️ **[디지털 방화벽]**: 3회의 모든 피해를 0으로 무효화하는 절대 쉴드 보유.
  * ⚡ **[알고리즘 과속]**: 이동속도 1.55배의 초고속 돌진 공격.
* **엘리트 보상**: 처치 시 100% 확정 황금 보물상자 + 보너스 30~55 Gold 드롭!

### 2. 🔮 히든 세트 시너지 시스템 (Synergy & Set Effects)
* 무기/패시브의 특정 조합 완성 시 고유 네온 세트 효과 발동:
  * 💼 **[사무직의 분노]** (클린 탄환 + 방화벽 지뢰 + 공격력 앰플): 모든 넉백 2배, 지뢰 폭발 범위 +40%, 25% 연쇄 폭발.
  * 🚫 **[디지털 셧다운]** (디톡스 레이저 + 셧다운 단두대 + 치명타경): 치명타 적중 시 적 1.5초 완전 정지(기절), 처형선 35%로 강화.
  * 💰 **[자본주의 폭격]** (디톡스 미사일 + 클린 탄환 + 황금 보너스): 타격 시 2% 확률로 골드 드롭, 골드 획득 시 1초간 이속 +20%.
  * 🛡️ **[완전 멸균 결계]** (소독 안개 + 가디언 위성 + 쇼크 펄스): 주변 4m 절대 보안 구역 형성(적 이속 -50% & 초당 40 정화 벼락).

### 3. ⏱️ 철야 야근 모드 (Endless Overtime) & 하이퍼 모드 (Hyper Mode)
* ⚡ **하이퍼 모드**: 출동처에서 토글 가능. 속도 1.25배, 적 스폰 30% 단축, 클리어 보상 **2.0배(200%)** 폭증!
* ⏱️ **철야 야근 모드**: 5분(300초) 생존 완료 시 바로 끝나지 않고 **[정시 퇴근(승리)]** vs **[철야 야근(무한 생존 도전)]** 선택! 야근 시 5분 이후 30초마다 적 스펙 폭주, 초과 생존 초당 4.5G 추가 성과급 지급!

### 4. 🐶 디톡스 서포트 펫 / 뽀모도로 드론 (Companion System)
* 플레이어를 졸졸 따라다니며 보조하는 든든한 파트너:
  * 🐕 **[산책견 댕댕이]**: 주변 8.5m 내의 보석과 상자를 플레이어에게 고속으로 물어다 줌.
  * 🐱 **[단잠 냥이]**: 14초마다 힐링 쉼터 장판을 깔아 체력 22 회복 & 도파민 과부하 20% 정화.
  * 🤖 **[뽀모도로 드론]**: 25초 집중 사격(주기적 레이저) + 5초 휴식(경험치 획득량 2배) 사이클 반복.

### 5. ⚙️ 종합 환경 설정창 (Audio Settings & Options)
* **BGM & SFX 개별 슬라이더 (0~100%)**
* **전체 사운드 음소거(Mute) 원클릭 토글**
* **화면 흔들림(Camera Shake) On/Off**
* **스피드런 밀리초(ms) 타이머 On/Off**

### 6. 🏆 업적/도감, ⚡ Q 궁극기, 🗺️ 레이더 나침반, 🎲 슬롯 자판기
* 12종 업적 DB 및 달성 시 골드/카르마 실시간 보상 & 상단 네온 토스트 배너.
* 4종 요원 Q 고유 궁극기 (빗자루 대청소 / 법적 면책권 / 긴급 통제 / 자본의 힘).
* 우측 상단 160×160 레이더 패널 및 시야 밖 멘탈 쉼터(⛲), 보스(👑), 상자(🎁) 거리 안내 나침반.
* 필드 50G 배팅 럭키 자판기 및 피의 계약/마하 계약 암거래.
* 순수 C# 프로시저럴 8-Bit BGM 신스 엔진 (Town 105 BPM, Battle 138 BPM, 피버 시 1.25배 가속).
