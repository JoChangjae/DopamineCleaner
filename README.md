# 🧠 도파민 클리너 (Dopamine Cleaner)

현대인의 뇌를 잠식하는 잡생각, 숏폼 알고리즘, 졸음 몬스터를 시원하게 정화하는 **2D 탑다운 뱀서라이크(Survivors-like) 로그라이트 액션 게임**입니다.

---

## 🎮 게임 정보

* **엔진**: Unity 6 (6000.6.4f1)
* **장르**: 2D Roguelite, Survivors-like, Bullet Hell
* **개발 언어**: C# (.NET Standard)
* **타겟 플랫폼**: PC (Steam), 모바일 (Android/iOS)
* **외부 종속성**: 외부 상용 에셋 0% (완전한 절차적 프로시저럴 C# 텍스처 & 오디오 신디사이저 렌더링)

## 🕹️ 조작법 (Controls)

| 키 | 동작 | 상세 설명 |
| :--- | :--- | :--- |
| **W, A, S, D** / 방향키 | 2D 8방향 이동 | 플레이어 기동 |
| **Space** / **Left Shift** | 무적 회피 대시 (Dash) | 0.25초 완전 무적 및 2.4배 속도 도약 |
| **Q** | ⚡ 요원 고유 궁극기 | 요원별 필살기 전개 (빗자루 대청소 / 법적 면책권 / 긴급 통제 / 자본의 힘) |
| **E** | 🎰 럭키 자판기 상호작용 | 필드 슬롯머신 배팅 및 하이리스크 암거래 계약 |
| **1** (숫자키 1) | 💊 응급 구급약 사용 | 인벤토리 비상약 즉시 투약 (HP +40) |
| **P** / **ESC** | 일시정지 (Pause) | 장비 현황판, 사운드 토글, 조기 철수 정산 |
| **마우스 클릭** | UI 상호작용 | 레벨업 카드 선택 및 본부 시설 이용 |

## ⚔️ 5대 최신 핵심 시스템 (New Feature Additions)

### 1. 🏆 디톡스 실적 & 해금 도감 (Achievements & Codex)
* **12종 고유 업적 시스템**: 잡생각 소독 누적(1/100/1,000마리), 초집중 피버 마니아, 거대 보스 격퇴, 3단 무기 동시 진화, 멘탈 쉼터 회복, 7-7-7 잭팟, 궁극기 전개 등.
* **실시간 달성 보상**: 업적 달성 시 대량의 골드 및 디톡스 카르마 포인트를 즉시 적립하며, 인게임 화면 상단에 골드 네온 팝업 토스트 배너 출력.
* **본부 5번째 전용 탭**: 본부(HQ)에 실시간 진행률(0~100%) 프로그레스 바 및 카드형 도감 UI 제공.

### 2. ⚡ 요원별 고유 궁극기 (`Q` 키 필살기)
* **🧹 김인턴 [전면 대청소]**: 반경 4.5m 내 모든 몬스터를 빗자루로 강력 넉백(80 대미지)시키고 화면 내 날아오는 모든 적 투사체 소멸.
* **🛡️ 박사정 [법적 면책 특권]**: 4.0초간 완전 무적 상태에 돌입하며 반경 3.8m 내 적들에게 95 대미지의 감전 충격파 방출.
* **🚨 강반장 [긴급 현장 통제]**: 화면 전체 몬스터에게 45 대미지를 입히며 4.5초간 80% 이동속도 급격한 둔화(슬로우).
* **💼 윤이사 [자본의 힘]**: 화면 전체 150 대미지 황금 폭풍 폭격 + 현금 50 Gold 즉시 적립 + 전맵 자석(마그넷) 보석 자동 흡수.
* **하단 HUD 연동**: 남은 쿨타임 원형 게이지 및 실시간 잔여 초(s) 시각화.

### 3. 🗺️ 나침반 레이더 미니맵 & 방향 인디케이터 (Minimap & Radar)
* **우측 상단 160×160 레이더 패널**: 네온 글래스모피즘 원형 스코프 스타일로 플레이어 및 주변 환경 렌더링.
* **화면 외곽 목표물 실시간 추적 (나침반 화살표)**:
  * ⛲ **멘탈 쉼터**: 청량한 민트색 인디케이터 및 남은 거리(m) 표시.
  * 👑 **도파민 보스**: 위협적인 붉은색 해골/왕관 인디케이터 및 거리 표시.
  * 🎁 **황금 보물상자**: 황금빛 선물상자 아이콘 및 거리 표시.
* 시야 밖 멀리 떨어진 핵심 오브젝트를 화면 가장자리에서 직관적으로 찾아갈 수 있어 맵 탐색 피로도 해소.

### 4. 🎲 도파민 럭키 슬롯 자판기 & 암거래 계약 (Lucky Slot & Dark Deals)
* **월드 필드 상호작용 (`[E]` 키)**: 작전 필드에 네온 자판기 배치. 접근 시 말풍선 안내 팝업.
* **50 Gold 배팅 3릴 슬롯머신**:
  * 7️⃣-7️⃣-7️⃣: **초대박 잭팟!** 황금 상자 2개 즉시 투하 + 150G 적립 + 피버 모드 즉시 발동!
  * 💎-💎-💎: **다이아몬드 대박!** 250 EXP 대량 보석 + 전맵 자석 흡수.
  * 🍒-🍒-🍒: **달콤한 체리!** 체력 100% 완전 회복 + 멘탈 케이크 드롭.
  * 💀-💀-💀: **도파민 과부하 꽝!** 스팸 슈터 기습 특수 웨이브 소환.
* **하이리스크 암거래 계약**:
  * 🩸 **피의 계약**: 받는 피해 +30% 리스크를 감수하고 전체 공격력 +45% 영구 폭증.
  * ⚡ **마하 계약**: 최대 체력 -25 페널티를 안고 이동속도 및 공격주기 +35% 극대화.

### 5. 🎵 런타임 8-Bit 신스 BGM 엔진
* **순수 C# 프로시저럴 합성 오디오**: 외부 mp3/wav 파일 없이 런타임 44.1kHz 사인파/사각파 알고리즘으로 BGM 실시간 렌더링.
* **테마별 배경음악**:
  * 🏛️ **본부(Town HQ)**: 편안하고 차분한 105 BPM 칠합 멜로디 루프.
  * ⚔️ **전투(MainGame)**: 박진감 넘치고 긴장감 있는 138 BPM 테크노 칩튠 루프.
* **동적 피버 가속**: 초집중 디톡스 피버 모드 돌입 시 BGM 템포가 **1.25배 가속(Pitch Boost)**되어 몰입도 극대화.
* **사운드 토글 연동**: 상단 스피커 버튼 및 일시정지 창에서 SFX와 BGM 음소거 동기화.

  * 맑은 고딕(Malgun Gothic) 및 OS 폰트 폴백 100% 완비 (네모 깨짐 현상 제로).
* **스마트 정보 배치**:
  * 상단 HUD: 체력 바(그린), 경험치 바(바이올렛), 피버 게이지(황금 펄스), 생존 시간, 킬 수.
  * 하단 HUD: 대시 쿨타임 인디케이터, Q 궁극기 활성화 뱃지.
